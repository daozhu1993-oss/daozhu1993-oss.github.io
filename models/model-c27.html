先一句话总览

Overview
C
c

写这个系列，我挑的都是能拿来用的框架，不玩虚的。数据预测模型 这篇，先看总览。

一句话总览： 数据预测模型就一句话——用定性和定量两把尺，把模糊的"未来"量成一条能看的线。定性（直觉+逻辑）定方向，定量（数据+模型）定数值，二者合起来才稳。
Origin
岛主思维模型体系融直觉、逻辑、数据、网络多方信号，提出者未单列。
Field
数据分析 / 决策把"下季度多少"从拍脑袋变成有依据。
Core Definition
两把尺：定性 + 定量直觉、逻辑定方向；数据、网络定数值。
Thinking Layer
预测决策层给不确定系上一根绳，让决策有依据。

Bad vs Good

四条思路拼图

The Four Inputs
01

直觉 Intuition

老手的嗅觉，能先嗅到拐点。但直觉是起点不是结论，别拿它当证据，老炮也会看走眼。

例：经验是导航不是判官。
02

逻辑 Logic

因果推演，像"降价→转化升→利润变"。没逻辑链的预测只是许愿，经不起三问就露馅。

例：因果要能讲通，才落得了地。
03

数据 Data

历史的回声，用趋势、同比环比外推。过去不代表未来，但完全无视过去更蠢，那是闭眼跳崖。

例：数据至少给个锚点。
04

网络 Network

群体智慧，整合多方信号交叉验证。单一来源容易被盲区埋，三个数据源好过一个权威。

例：互证才稳，兼听才明。

上手四步

From Guess to Range
1
先问"靠什么判断"直觉/逻辑/数据/网络，至少占两样，别全凭感觉下注。
2
给预测标区间写乐观/中性/悲观三行，别给死数，未来本就带误差。
3
标最危险的假设每次预测都写清"最危险的假设是什么"，翻车才知道错在哪。
4
事后复盘偏差校准你的"预测肌肉"，下次比这次准，错在假设还是执行分得清。
