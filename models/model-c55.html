写这个系列，我挑的都是能拿来用的框架，不玩虚的。分形理论 这篇，先看总览。

一句话总览： 分形是"整体和局部长得像，但每一片都在悄悄进化"。好企业不靠推翻自己换物种，而是把老 DNA 灌进新业务，在同一棵树上发新芽——传承是根，变异是芽，市场挑活下来的。
Origin

Field
企业创新 / 战略规划 / 组织进化凡是"老树发新芽"的增长现场。
Core Definition
相似中的进化局部像整体，又各有变异。

四个关键要点

The Four Moves
01

分形 = 相似中的进化

局部保留整体的形状，又各有变异。像一棵树的每根枝，都像整棵树。

02

生物分形进化

遗传 + 变异 + 自然选择 = 进化。传承是根，变异是芽，环境挑活下来的。

03

企业分形进化

优良传统 + 业务破局 + 市场选择。老 DNA 别扔，新突变要敢试。

04

关键判断

最好的创新不是推翻自己，是在自己身上长出新枝。
