Overview

写这个系列，我挑的都是能拿来用的框架，不玩虚的。高效赋能感模型 这篇，先看总览。

一句话总览： 赋能的关键不在你给了多少权，而在员工心里有没有「赋能感」。目标感、支持感、参与感、认同感、获得感，五感凑齐，人才真被点燃；缺任何一感，赋能感就漏风。
Origin
蒋小华《赋能工作法》体系下点破的「赋能感」盲区框架。
Field
领导力 / 团队激励授权了人却不起劲、说「我信任你」对方却懵时，用它找原因。
Core Definition
五个感目标感·支持感·参与感·认同感·获得感。
Thinking Layer
心理层 / 感受赋能在「授权动作」之外，造出「被赋能」的感觉。

只授权 vs 造赋能感

Bad vs Good
✗ 误用

只做授权动作

Delegation Only
口头说「全权交给你」，人却一脸懵
不露面、不反馈、没奖励，支持认同获得全空
以为给了权，对方就该自动发力
三个月后对方躺平，还怪他不争气
例：例：老板说「全权交给你」，可从不露面、不反馈、没奖励，三个月那人躺平了。
✓ 善用

造出「赋能感」

Sense of Empowerment
目标感 + 支持感：知道为什么干、感到有人撑腰
参与感 + 认同感：觉得自己真掺过手、被认可
获得感：在团队里真有收获（能力 / 绩效 / 待遇）
五感凑齐，人才从「等指令」变「自己跑」
例：例：对照五感打分，哪感最空先补哪感，人重新被点燃。

五感拆解

The Five Senses
01

目标感

知道为什么干。没目标的授权是放羊。

02

支持感

感到有人撑腰。没支持的自由是孤立。

03

参与感

觉得自己真参与了。人不为「被分配的活」拼命，只为自己「掺过手的事」上心。

04

认同感

被认可。被看见、被肯定，才愿意多扛。

05

获得感

真有收获（能力 / 绩效 / 待遇）。五感缺任何一感，赋能感就漏风。

落地五步

Build the Sense
1
对照五感打分哪感最空，先补哪感，别撒胡椒面。
2
给目标感说清为什么干，不只是干什么。
3
补支持感露面、反馈、兜底，让他感到有人撑腰。
4
放进参与认同关键决策让他真有发言权、被认可。
5
兑现获得感能力 / 绩效 / 待遇真有长进，别只画饼。
