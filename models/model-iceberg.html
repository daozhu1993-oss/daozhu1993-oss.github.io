Overview

写这个系列，我挑的都是能拿来用的框架，不玩虚的。冰山模型 这篇，先看总览。

一句话总览： 冰山模型告诉我们，一切外在行为（争吵、冷战、讨好）都只是内在冰山露出的一角——要真正解决关系矛盾，必须潜入水下，看清行为背后的感受、期待与渴望。它既是看清他人的工具，也是通往自我理解的桥。
Origin
维吉尼亚·萨提亚（Virginia Satir）家庭治疗先驱，在萨提亚模式中系统提出"内在冰山"。
Field
心理学 / 亲密关系 / 沟通 / 自我成长凡是有情绪、有关系的场合都用得上。
Core Definition
7 层内在结构行为→应对方式→感受→感受的感受→观点→期待→渴望。
Thinking Layer
洞察共情层在"看现象"之下，练习"看动因"。

只看行为 vs 潜入冰山

Surface vs Depth
✗ 误用

只盯水面行为

React to the Tip
对方发火，你立刻回击或冷战
只看见"你从不关心我"的指责
用权力斗争压过对方，非要争输赢
情绪过后更内耗，问题原地打转
例：例：伴侣玩手机，你吼"你从来都不关心我"——只打到冰山尖，矛盾越积越深。
✓ 善用

潜入水下冰山

Dive Beneath the Surface
先识别行为与姿态，不急着回击
探索愤怒之下的受伤与孤单
表达渴望而非指责行为
从权力斗争，走向深度联结
例：例："你一直看手机，我会感到孤单，期待我们能聊聊天"——把指责换成渴望，对方听进去了。

冰山藏着的 6 层

Six Layers Underwater
01

行为 + 应对方式

水面可见的部分：争吵、沉默、指责。应对方式有 5 种——指责、讨好、打岔、超理智、一致性。怒吼往往是"指责型"姿态，用攻击保护自己。

02

感受

行为背后的直接情绪：愤怒、委屈、受伤。愤怒之下，常常其实是"我很孤单、很失望"。

例：对伴侣大吼，真正的感受是受伤，不是愤怒本身。
03

感受的感受

你对自己情绪的评价，常带来二次伤害。"我竟为这点小事生气，我太糟糕了"——这种自我批判比原情绪更伤人。

04

观点 / 信念

深信不疑的想法："爱我就应该懂我""不说也能猜到，才是真的在乎"。这些信念，是矛盾反复发生的底层脚本。

05

期待

对自己、对他人的具体希望："我期待难过时，他能主动安慰我"。未被满足的期待，是情绪的导火索。

06

渴望（最底层）

全人类共有的心理需求：被爱、被接纳、有价值。所有行为的终极指向，都是渴望"确认自己值得被爱"。

例：吵架吵到最后，其实都是在要一句"你依然爱我"。

3 步实操法（扩展版）

Stop · Dive · Connect
1
停：按下暂停键情绪上头先别回击，识别"我/对方此刻的行为与姿态是什么"，留出喘息的空间。
2
潜：探索水下问自己：真实感受是什么？背后有怎样的观点和期待？别停在水面的指责上。
3
通：表达渴望用"我"句式说出感受与期待，而非攻击行为："我感到孤单，期待我们能聊聊"。
4
练：把情绪当邀请每次波动，都当成冰山在邀请你关爱柔软的自己；事后做一次简短复盘。

In a Nutshell

马上能用的事

Put It to Work
✓

争吵时先喊"停"

别急着回击，给自己三秒，识别当下的行为与姿态。

✓

把"你怎么这样"换成"我感到"

用"我"句式表达感受与期待，对方才听得进去。

✓

写下你真正的"渴望"

每次生气，问一句：我到底在渴望被爱、被接纳，还是被看见？

✓

识别自己的应对姿态

你是习惯指责、讨好，还是打岔？看清模式，才能松动它。

✓

对他人多一层好奇

对方"不可理喻"时，猜猜 ta 水下藏着什么脆弱。

✓

每周一次情绪复盘

挑一件情绪波动的事，用冰山画一遍，越画越清醒。
