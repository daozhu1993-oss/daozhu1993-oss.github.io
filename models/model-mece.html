MECE 原则

Mutually Exclusive, Collectively Exhaustive
巴巴拉·明托  ·  Barbara Minto  ·  《金字塔原理》· 麦肯锡方法论
MECE
相互独立完全穷尽先定维度画树检查

先一句话总览

Overview
MECE
Mutually Exclusive
Collectively Exhaustive

写这个系列，我挑的都是能拿来用的框架，不玩虚的。MECE 排在最前，是因为我见过太多人——把问题拆得七零八落，自己还觉得挺清楚，结果会议纪要写满三页，没一个人真看懂。

一句话总览： MECE 是「相互独立、完全穷尽」的分类纪律。说人话：把一团乱麻拆成几块，块与块不重叠、加起来不漏底。它不替你想答案，但能保证你既没在重复劳动，也没漏掉盲区。麦肯锡那套结构化思考，地基就在这四个字上。
Origin
巴巴拉·明托Barbara Minto，麦肯锡首位女性顾问，1970 年代在《金字塔原理》里系统提出。
Field
结构化思维 / 商业分析咨询、战略、产品与日常管理中的「拆解」底层方法论。
Core Definition
两大分类铁律相互独立（Mutually Exclusive）+ 完全穷尽（Collectively Exhaustive）。
Thinking Layer
拆解层 / 结构化在「系统 2 慢思考」之上，再叠加一道分类纪律。

MECE 思维

Mutually Exclusive & Exhaustive
维度单一清晰，块与块互不重叠
所有分类相加 = 全集，没有漏网
用稳定维度切：时间 / 结构 / 流程 / 公式
可逐层下钻，每层都过检验
例：按「注册时长 × 消费额」两维度画矩阵，每个用户恰好落在一个格子，且覆盖全部。

MECE 四律

The Four Disciplines
01

相互独立（ME）

任何一条信息只属于一个分类，不脚踏两条船。重叠是重复劳动和口径打架的根源——你以为在分工，其实在重复。

02

完全穷尽（CE）

所有分类加起来必须等于全集。出现大块「其他」之前，先确认它真的小到可以忽略，而不是你懒得再拆。

03

先定维度，再拆分

用稳定维度切（时间 / 结构 / 流程 / 公式 / 人群），一次只用一个主维度，别混搭。维度一乱，分类必乱。

例：利润 = 收入 − 成本，沿变量拆，天然 MECE。
04

画树状图 + 检查

把层级画成树，每一层都问一遍：有重叠吗？漏了吗？可视化让盲区无所遁形，脑子空想最容易漏。

应用流程（五步走）

From Problem to MECE
1
明确问题边界：先搞清楚「到底在拆什么」，别上来就分。边界模糊，分类必乱。
2
选一个主维度：时间 / 结构 / 流程 / 公式 / 人群，挑一个最贴合的，一次只用一个。
3
第一层拆解：把全集切成 3–5 个互斥块，太少漏、太多乱，黄金区间在 3–5。
4
检查 MECE：逐块问：重叠？遗漏？补「其他」前先确认它是真的小头。
5
逐层下钻：对关键块重复 2–4 步，直到每一块都能直接行动为止。

马上能用的事

Put It to Work
✓

汇报前 MECE 自查

进会议室前先问自己：我的分类有重叠吗？有遗漏吗？两条都过，再说。

✓

警惕「其他」

看到大块"其他"先停一下——那往往是你随手丢掉的盲区，不是真的小头。

✓

公式法找维度

利润=收入−成本、增长=新客+回流，沿变量拆，天然互不重叠。懒人最爱这一招。

✓

用户分群先定单一维度

生命周期切就别混年龄，否则必然重叠。一次一个维度，脑子才不乱。

✓

复杂问题先画一棵树

每画一层就问"这一层 MECE 吗"，比在脑子里空想靠谱十倍。

✓

团队对齐同一张树

用同一张 MECE 树讨论，避免各切各的、口径永远对不上。
