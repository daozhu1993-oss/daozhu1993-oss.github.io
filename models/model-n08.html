Field

Core Definition
把"高峰体验"从偶然变成可设计的四步走——E 欣喜、P 荣耀、I 认知、C 连接，主动给人造记忆隆起。峰值体验设计器
Thinking Layer
行为 / 体验设计峰值时刻

误用 vs 善用

Bad vs Good
✗ 误用

平淡无奇的"无记忆"经历

全程匀速，没有任何打破脚本的意外。
只给方案不让人体悟，对方毫无顿悟。
里程碑被略过，做完也没人庆祝。
只顾交付不顾意义，人和人没连接。
例：例：一场年会从开场念稿到结束发奖，全程平铺，员工下周就忘了——没有峰值，等于白办。
✓ 善用

被设计的"峰值时刻"

欣喜：打破常规脚本，加仪式感制造"记忆隆起"。
认知：让人自己看见真相，顿悟比灌输管用百倍。
荣耀：把大目标拆成里程碑，每个小胜都庆祝。
连接：赋予意义＋同甘共苦，把陌生人焊成战友。
例：例：度假村钢琴师临走专门弹了首日本歌送客——在"结尾"打破脚本，全场记住这家店。

EPIC 四要素

The EPIC Elements
01

E 欣喜 Elevation

博士服、婚纱都是给重要时刻加仪式感。生活太平淡就没人记得你，加点意外才有"记忆隆起"。

02

P 荣耀 Pride

山田本一将 40 公里拆成"银行、大树、红房子"逐个达成。荣耀不是终点才有，每个小里程碑都该庆祝。

03

I 认知 Insight

卫生项目让村民自己发现"苍蝇腿比头发沾更多屎"，当场羞愧改掉陋习——让人自己看见，比塞方案管用百倍。

04

C 连接 Connection

救生员实验里，"使命小组"比"个人受益小组"多干了 43% 的活儿。意义感能把陌生人焊成战友。

05

峰值-结尾定律

卡尼曼说：人对一段经历的记忆，只由峰值和结尾决定。守住结尾体验，就守住整体评价。

06

锚点优先

先圈出这段经历最该被记住的环节（开头 / 转折 / 结尾），再挑一种手法下手，别平均用力。

三步造峰值

How to Engineer a Peak
1
找锚点圈出这段经历里最该被记住的环节（开头 / 转折 / 结尾）。
2
四选一加惊喜、造顿悟、立里程碑、给意义，挑一个最顺手的。
3
守住结尾最后一步的体验，决定整体评价——别虎头蛇尾。
4
复盘峰值事后问一句：TA 记得的是哪个瞬间？下次加强它。

马上能用的事

Put It to Work
✓

给下次汇报/活动设一个"高峰"

开场或结尾加一个意外仪式，制造记忆隆起。

✓

把大目标拆成里程碑

每完成一个，公开庆祝一次，荣耀感即时到账。

✓

用"让人自己看见"代替说教

让对方发现答案，而非你直接给答案。

✓

给团队安个"使命"框架

把"为钱干"改成"为谁解决什么"，连接感上来。

✓

守住结尾

任何服务、任何见面，最后一步都精心安排。

✓

列"峰值清单"

你想被记住的 3 个瞬间，本季度逐个落地。
