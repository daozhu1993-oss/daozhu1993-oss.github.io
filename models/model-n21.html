Thinking Model · No.128

承诺升级

Escalation of Commitment
失败后不但不停手，反而往坑里继续扔资源——这不是坚持，是上头。
N
01020304

先一句话总览

Overview
N
n

写这个系列，我挑的都是能拿来用的框架，不玩虚的。承诺升级 这篇，先看总览。

一句话总览： 承诺升级指人在项目失败后，不但没有及时止损，反而因为沉没成本、自我辩护和损失厌恶继续加码投入，直到彻底崩盘——正确的坚持叫定力，错误的坚持叫上头。
Origin
管理心理学 · 1976 年命名决策陷阱研究（素材未标具体提出者）
Field
决策心理学 / 管理项目投资、组织行为
Core Definition
人在失败后不但不停手，反而往坑里继续扔资源，用更多投入证明"我没错"。沉没成本＋自我辩护＋损失框架的合力
Thinking Layer
决策 / 认知止损与自我觉察

误用 vs 善用

Bad vs Good
✗ 误用

跪着也要走完自己选的路

前面砸越多越舍不得撤，"都付出这么多了"
承认错＝打自己脸，于是找借口证明没错
面对损失赌性大发，宁可冒险翻本
高估掌控力＋捂盖子，错误滚雪球
例：例：史玉柱把巨人大厦从 38 层加到 70 层，投资 2 亿变 12 亿，资金链断裂负债 2.5 亿。
✓ 善用

到止损线，潇洒离场

投前写死"亏到 X 就撤"，到线就走
决策与评估分离，做的人不能自己判自己
定期开"证伪会议"，专找项目会死的证据
把"认错"当成本，不当丢脸
例：例：设好止损线的基金经理，亏到阈值立刻平仓，保住本金等下一局。

关键要点

Key Points
01

第一层：沉没成本作祟

前面砸的时间钱越多越舍不得撤，自欺"自己选的路跪着也要走完"。

02

第二层：自我辩护

内部辩护骗自己、外部辩护骗别人，骗着骗着就真信了——承认错等于打脸。

03

第三层：前景理论的损失框架

人面对损失赌性大发，宁可冒险翻本也不接受确定的亏——亏 50 万时反而敢再押 50 万。

04

第四层：控制幻觉＋组织捂盖

高估自己掌控力＋信息不透明，错误像滚雪球（巴林银行就这么没了）。瞒一次，就有第二次。

05

一句话刹车

正确的坚持叫定力，错误的坚持叫上头——区别在于有没有止损线。

三步刹车

Hit the Brakes
1
识别信号你开始用"都投了这么多"当继续的理由——这是承诺升级的第一声警报。
2
拉出止损线投前写死"亏到 X / 做到 Y 就撤"，白纸黑字，到线就走。
3
分权评估让没参与决策的人来判项目死活，做的人不能自己判自己。
4
证伪会议定期专门找项目会死的证据，而非只听好消息。

马上能用的事

Put It to Work
✓

给每个项目画止损线

今天给手头最纠结的事写一条"到 X 就撤"，别让它无限滚。

✓

找局外人打分

下周把卡住的项目讲给没利益关系的朋友听，借第三方眼睛看死活。

✓

开一次证伪会

团队例会专列"这个项目会怎么死"，只找反证。

✓

重命名"认错"

把承认错误当及时止损的成本，不当丢脸的事。

✓

复盘加码史

列你最近一次"越亏越加注"，写下当时响起的信号。
