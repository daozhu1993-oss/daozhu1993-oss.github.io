沉没成本效应

Sunk Cost Effect
已经花掉、收不回来的钱和时间，会像黑洞一样吸着你继续往下跳。

先一句话总览

Overview
N
n

写这个系列，我挑的都是能拿来用的框架，不玩虚的。沉没成本效应 这篇，先看总览。

一句话总览： 沉没成本效应说：那些已经发生、再也收不回来的投入，会悄悄绑架你的下一个决定——你越投入，越舍不得抽身，于是越陷越深。看透它，是把"过去的账"和"未来的账"分开算的开始。

Core Definition
已发生且不可收回的投入，会让人非理性地继续投入核心是"泼出去的水"与"当下选择"是两笔账
Thinking Layer
决策 / 认知管住"要不要继续"的那一念

误用 vs 善用

Bad vs Good
✗ 误用

被过去的账绑住

票都买了，烂片也得看完——用"已经花了"替"值不值得"做主。
输了想翻本，跌了硬扛，因为"前面都白扔了"而被迫继续扔。
承认错了太疼，于是追加投入好让当初的决定"显得没白费"。
把"坚持"当美德，谁先放手谁就输了，烂项目拖成无底洞。
例：例：买错股票不认，越补越亏，最后血本无归，只因"已经套了这么多"。
✓ 善用

把账切两笔

决策只看未来收益，不回头数过去的花费。
引入局外人视角——新来的经理对前任的沉没成本不敏感，反而看得清。
给"放弃"正名：公开放弃烂项目，本质是在止损。
像甘地丢鞋：一只掉了，把另一只也扔下去，让捡到的人凑成一双。
例：例：电影看到一半烂得想吐，立刻离场——票钱不会回来，但剩下的两小时归你了。

三个层级，看清它怎么套住你

Three Layers
01

沉没成本 = 泼出去的水

它已发生、不可收回，跟"现在该不该继续"完全无关。看烂片中途离场，票钱也不会回来。

02

损失厌恶让你越陷越深

人对"已亏"的痛，远大于对"将赚"的喜。所以骗子先让你交300，再骗你交2000——你怕前面白扔，只能继续扔。

03

认知失调逼你自圆其说

承认"我错了"太疼，于是继续追加，好让当初的决定显得没白费。这是沉没成本最隐蔽的帮凶。

04

它专挑"渐进投入"下手

一次性大出血你会立刻收手，但温水煮青蛙式的慢慢投入，最容易让你忘记"其实早该停了"。

05

止损不是认输，是止损

在烂事上及时喊 cut，省下的时间和心力，才是你真正的资产。

识别信号 → 应对

Signal → Response
1
识别"不愿离场"信号当你用"都花了/都谈了/都做了"来论证继续时，警报就响了。
2
切两笔账把"已投入"和"当下选择"分开：决策只问"从这一刻往后，收益还划算吗"。
3
借局外人眼睛找个不背着这段历史的人帮你看——新人对沉没成本天然不敏感，反而清醒。
4
给放弃正名把"止损"写成胜利：砍掉烂项目、结束消耗关系，是成年人的高级自律。
5
设"退出红线"事前约定最坏边界（亏到X、拖过Y天就撤），别等情绪上头再算。

马上能用的事

Put It to Work
✓

列一笔"不愿离场"清单

写下你最近哪笔投入其实早该喊 cut，只列不评判。

✓

给重大决策设退出红线

在开始前写清楚：亏到多少、拖过多久就撤，贴在显眼处。

✓

找个"局外人朋友"

挑一个不掺和你的历史的人，关键时刻请他帮你喊停。

✓

把"放弃"改个说法

以后砍项目别说"我失败了"，说"我在止损"。

✓

离场练习

下次遇到烂片/烂局，故意中途离场一次，体会"省下时间"的爽感。

✓

拆穿自己的"都花了"

每次想用过去投入论证继续，先反问：如果现在从头，我还会开始吗？
