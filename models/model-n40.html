归因理论

Attribution Theory
你怎样解释成败，就写下怎样的人生剧本。

先一句话总览

Overview
N
n

写这个系列，我挑的都是能拿来用的框架，不玩虚的。归因理论 这篇，先看总览。

一句话总览： 人总爱给成败找原因，而且找得极其双标——解释别人用内因、解释自己用外因。归因的方式，决定了你下次还会不会进步。
Origin
社会心理学 · 海德（1958 开创）后续由韦纳等发展为成败归因框架
Field
社会心理学 / 自我认知研究人如何解释自己与他人的行为
Core Definition
人给成败找原因，且极双标：对外归内因、对己归外因归因模式塑造行为循环
Thinking Layer
认知 · 成长属于"复盘自己"那一层

误用 vs 善用

Bad vs Good
✗ 误用

双标归因：功劳归己、黑锅推人

别人完不成，你觉得"他不努力"（内因）。
轮到自己，就是"环境所迫"（外因）。
房价涨了"我眼光好"，跌了"开发商虚高"。
失败归"我天生不行"，陷进悲观循环。
例：例：团队一这么干，功劳往自己兜里塞、黑锅往外推，就再也找不着真因，下次还摔同一个跟头。
✓ 善用

模型视角：把原因归到能改的地方

切换观察者视角：先假设旁观者会怎么解释。
找"可控+不稳定"因：努力、方法这些能改的。
写真因清单：大事后逼自己列3条客观原因。
失败归"偶然+可调"，走良性循环。
例：例：项目黄了，不甩锅"市场不好"，而是写下"我低估了交付周期、没提前对齐需求"——这两条下次真能改，复盘才有用。

关键要点

Key Points
01

第一层：基本归因偏差

解释别人用内因（"他不努力"），解释自己用外因（"环境所迫"）。这套双标，人人都中。

02

第二层：自我服务偏差

功劳往自己兜里塞，黑锅往外推。房价涨了是眼光，跌了是开发商——团队一这么干就找不到真因。

03

第三层：习惯成性格

韦纳说成败可归六因素，关键在"可控还是不可控"。老归"我天生不行"，就越活越丧。

04

三大堵点

岛主提醒：浅层归因（"我控制不住"）、外部归因（"都怪别人"）、片面归因，是进步的三道墙。

05

关键在"可控+不稳定"

把失败归到努力、方法这些能改的地方，才走良性循环；归到天赋、命运，就锁死自己。

校准归因的三步

Recalibrate Your Attribution
1
切：换旁观者视角先假设自己是局外人，会怎么解释这件事？往往一眼看出自己正在甩锅。
2
找：定位可控因把原因归到努力、方法、节奏这些能改的地方，而不是天赋、运气、别人。
3
写：列真因清单每次大事后逼自己写3条客观原因，别让借口溜走，复盘才有重量。
4
改：落到下次行动从清单里挑一条能改的，写成具体动作。归因的终点不是认错，是改对地方。

马上能用的事

Put It to Work
✓

下次成功，先别急着领功

问自己：有多少是运气和外界？把客观成分也写下来，避免自我服务偏差。

✓

评价别人前，先想环境

别人掉链子，别秒判"他不努力"，先想想他面临的外因，破除基本归因偏差。

✓

失败写3条客观因

大事后逼自己列3条真原因，至少一条是"我可控可改"的，别全推给外界。

✓

把"我不行"换成"我没做对"

用"可控+不稳定"替代"天生不行"，把悲观循环改成良性循环。

✓

团队复盘对事不对人

带团队时立规矩：找原因先找可改的，不让甩锅文化冻住成长。
