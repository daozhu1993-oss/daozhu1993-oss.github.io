证实偏差

Confirmation Bias
证实让你舒服，证伪让你正确。
N

先一句话总览

Overview
N
n

写这个系列，我挑的都是能拿来用的框架，不玩虚的。证实偏差 这篇，先看总览。

一句话总览： 一旦信了某个念头，你就疯狂搜集支持它的证据、对反面的视而不见，还觉得自己超客观——大脑天生爱自洽，哪怕自洽在骗你。
Origin
认知心理学 · 波普尔（可证伪性）属认知偏差家族；波普尔从科学哲学点出"可证伪"
Field
认知心理学 / 批判性思维解释人为何只看得见想看的
Core Definition
先有结论再找证据，对反面信息选择性失明律师思维，而非法官思维
Thinking Layer
认知 · 决策属于"保持客观"那一层

误用 vs 善用

Bad vs Good
✗ 误用

直觉陷阱：先开枪，再画靶

认定领导针对你，专挑他凶你的瞬间记。
喜欢谁就攒喜欢理由，讨厌谁就攒讨厌理由。
四卡片题九成人翻错：只验"支持"不验"证伪"。
抽烟的人说"抽烟缓解压力"，自我洗脑。
例：例：庞氏骗局里，那么多人坚信"这个项目能赚"——只盯着利好，对报警信号一律屏蔽，越陷越深。
✓ 善用

模型视角：主动证伪

换"法官思维"：先找能推翻想法的证据。
信波普尔：科学靠可证伪，不靠可证实。
用芒格法：反过来想，总是反过来想。
一条打脸证据，贵过十条支持。
例：例：岛主曾坚信某个投资逻辑，天天刷利好，直到朋友一句"你看过反面数据吗"把他锤醒。此后养成习惯——先找打脸证据，才敢掏钱。

关键要点

Key Points
01

第一层：先开枪再画靶

先有结论再找证据。喜欢刘德华就攒一堆喜欢理由，讨厌谁就攒一堆讨厌理由。这是"律师思维"，不是"法官思维"。

02

第二层：三种心理推着你

认知闭合（怕混沌）、认知失调（不想拧巴）、错误规避（怕担责）。大脑天生爱自洽，哪怕自洽在骗你。

03

第三层：破解靠证伪

波普尔说科学靠可证伪，不靠可证实。找一个能推翻你想法的证据，比找十个支持的更值钱。

04

四卡片题的启示

规则"一面元音，反面必偶数"，九成人翻错——大家本能去验"支持"，却不懂该去验"能证伪"的那张。

05

同温层是偏差的温床

只待在认同你的圈子里，证据越收越单一。多读不同立场，才看得见自己盲区的形状。

识别信号 → 主动证伪

Spot & Disconfirm
1
信号：留意"越想越对"当你觉得"全网都赞同我""证据越找越顺"，先警觉：我在收集，还是在自我印证？
2
列：反对我的证据每次下结论，逼自己列一条"反对我"的证据。列不出，说明你还没真正检验过。
3
开：拍砖会重大决策专门开个"拍砖会"，请人证明它不行。让反对意见有了正式座位。
4
读：不同立场主动读对立观点，别待在同温层。看见反例，结论才立得住。
5
掏：先证伪再下注像岛主那样：先找打脸证据，才敢掏钱。证实让你舒服，证伪让你正确。

马上能用的事

Put It to Work
✓

下结论前先列反证

每次拍板，逼自己写一条"反对我"的证据。写不出，就别急着信。

✓

重大决策开拍砖会

请朋友专门证明它不行，给反对意见一个正式座位，别一个人自嗨。

✓

跳出同温层

这周主动读一篇你不同意的观点，看看反例长什么样，别只喂自己爱听的。

✓

投资先找打脸数据

像岛主：先找能推翻逻辑的反面数据，才敢掏钱，不让利好刷屏替你决策。

✓

把"律师思维"换"法官思维"

少问"怎么证明我对"，多问"什么能证明我错"，结论才立得住。
