心理账户

Mental Accounting
钱不是一律平等的——它按来源和用途分进不同"心口袋"，彼此不互通，于是 5000 的包舍得买、199 的课嫌贵。

先一句话总览

Overview
N
n

写这个系列，我挑的都是能拿来用的框架，不玩虚的。心理账户 这篇，先看总览。

一句话总览： 塞勒（2017 诺奖）发现，人会把钱开成多个不互通的"心理账户"；商家就靠拆账户、支付分离、交易效用拿捏你的钱包。
Origin
理查德·塞勒（R. Thaler）2017 年诺贝尔经济学奖
Field
行为经济学 / 消费心理理财、营销、消费决策
Core Definition
钱按来源与用途分账，不同账户互不融通辛苦钱、意外财、零钱各一本账
Thinking Layer
认知 / 决策行为偏差层

误用 vs 善用

Bad vs Good
✗ 误用

被账户拿捏

中奖 2000 立马花光，工资 2000 舍不得动——开了两个账户
交易效用坑——990 打五折觉着捡漏狂买，其实成本 80
支付分离——办年卡充会员，痛感减半，去年健身卡去三次
以旧换新、信用卡——把支付和消费拆开，像记在别人头上
例：例：岛主去年充了健身卡去三次——"感觉在投资不是在消费"，钱就这么悄摸花掉。
✓ 善用

反用账户

花钱前问"这钱若来自工资账户，我还买吗"——打破分账
大额决策把各账户统一成"总财富"再算
主动开"健康账户""学习账户"——把一笔钱单独划出，花起来不心疼
看穿交易效用——爽的是"占便宜感"，不是东西本身值
例：例：岛主反向用法——单独划"健康账户"每月自动扣健身费，主动给自己开个好账户，比被商家开强。

心理账户三坑

Source · Project · Trick
01

来源分账

辛苦挣的舍不得花，意外之财眨眼花光——同是钱，两个账户互不串门。

02

用途分账

自用账户嫌 5800 的包贵，送礼账户收下就开心，规则完全不同。

03

交易效用

标价 990 再五折，你觉着捡漏狂买——爽的是"占了便宜"的特殊账户。

04

支付分离

年卡、信用卡把花钱和消费拆开，痛感减半悄悄花掉，像记在别人头上。

反套路三招

Beat the Trick
1
同账户拷问花钱前问"这钱若来自工资账户，我还买吗"，破掉分账幻觉。
2
并总账大额决策把各账户合成"总财富"再算，不被局部账户骗。
3
主动开好账户给自己设"学习账户""健康账户"，每月自动扣，花得理直气壮。
4
识破交易效用凡"打骨折"先算真实成本，别为"占便宜感"买单。

马上能用的事

Put It to Work
✓

同账户测试

下次想买非必需品，先问"用工资账户的钱我还买吗"。

✓

并总账算大单

买大件前把所有账户合成一笔总财富，重新估价。

✓

开健康账户

每月自动划一笔进"健康账户"，健身花起来不心疼。

✓

拆穿五折

看到"原价990五折"先查成本，别为占便宜狂买。

✓

关旧账户

以旧换新前算清旧物残值，别被"关账户"套路轻易下单。
