写这个系列，我挑的都是能拿来用的框架，不玩虚的。七个习惯模型 这篇，先看总览。

一句话总览： 柯维在《高效能人士的七个习惯》里给出一句话地基：效能 = 产出与产能的平衡。那只下金蛋的鹅你得养着，光盯蛋不顾鹅，最后蛋鹅两空。
Origin

Field
自我管理 / 个人效能时间管理、人际关系、原则领导
Core Definition
效能=产出与产能的平衡，七个习惯撑起从依赖到互赖前三个管自己，中三个管关系，第七个充电
Thinking Layer
成长 / 自我管理也可归为认知——先扩影响圈

误用 vs 善用

Bad vs Good
✗ 误用

误用：杀鸡取卵式拼命

只盯产出（金蛋），不顾产能（鹅），996 猛冲直到身体垮
把精力耗在"关注圈"里抱怨环境、怪别人
合作玩零和，要么你赢要么我输
重要不紧急的事永远往后排，天天救火
例：例：前年 996 猛冲产出，鹅（身体）快垮了才醒悟——蛋没多下，自己先废了。
✓ 善用

善用：喂鹅也捡蛋

个人领域三习惯：积极主动（扩影响圈）、以终为始、要事第一（艾森豪威尔四象限）
公众领域三习惯：双赢思维、知彼解己（移情聆听）、统合综效（1+1>2）
第七习惯不断更新：在身体、精神、智力、社会情感四层面持续充电
把"重要不紧急"当喂鹅的草，先喂鹅再捡蛋
例：例：用"要事第一"把锻炼和家人排进周计划，产能回来，蛋反而下得更稳。

装好这套操作系统的 5 个要点

Key Points
01

效能=产出÷产能

金蛋是产出，鹅是产能；杀鹅求蛋，两空。很多人拼命追蛋，却舍不得养护下蛋的鹅。

02

个人三习惯（依赖→独立）

积极主动（管影响圈）、以终为始、要事第一。先把"自己"这块地种好。

03

公众三习惯（独立→互赖）

双赢思维、知彼解己、统合综效。从"我"走到"我们"，关系才增效。

04

第七习惯不断更新

身体 / 精神 / 智力 / 社会情感四个账户日日充钱，它撑起前面六个。

05

要事第一的诀窍

把精力压在"重要不紧急"上，那才是喂鹅的草，而非天天救火。

例：岛主用"要事第一"把锻炼和家人排进周计划，产能回来，蛋下得更稳。

三步装好这套系统

Install the OS
1
圈出"影响圈"只做圈内事，别把能量耗在抱怨上；圈会越做越大。
2
列"重要不紧急"清单本周先喂鹅再捡蛋，把锻炼、陪家人写进周计划。
3
每天留 10 分钟更新读几页书、动一动、认真听个人说话，给四个账户之一充钱。
4
合作先想双赢遇事问"怎么让双方都多拿"，而非你死我活。
