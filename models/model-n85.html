Thinking Model · No.192

群体盲思

Groupthink
一群聪明人，会因为太想"保持一致"，一起做出蠢决定。
N
01020304

先一句话总览

Overview
N
n

写这个系列，我挑的都是能拿来用的框架，不玩虚的。群体盲思 这篇，先看总览。

一句话总览： 当团队高度团结又有一位强势领导，异议会被悄悄压下去——一致不等于正确，沉默里常藏着事故的种子。
Origin
心理学家欧文·贾尼斯（Irving Janis）基于对猪湾事件等决策失败的复盘提出
Field
组织行为 / 决策心理学团队管理、群体决策场景
Core Definition
高凝聚团队为求一致，压制异议、简化思考，导致集体判断失真的现象一致≠正确
Thinking Layer
认知 / 决策群体层面的认知偏差

误用 vs 善用

Bad vs Good
✗ 误用

把"没人反对"当"大家都同意"

领导先表态，全场立刻跟上，谁反对谁"不团结"
把沉默误读成赞成，错也听不进
同质化圈子，听不到圈子外的声音
为保面子保留意见，把领导决策合理化
例：例：1961 年猪湾事件，肯尼迪精英幕僚一致点头，结果行动惨败，还间接引爆了 1962 年古巴导弹危机。
✓ 善用

把"沉默"当信号，而不是当赞成

指定"魔鬼代言人"专门唱反调
分组讨论再汇总，保护少数异见
用可信度加权，别让多数淹没专家
领导最后发言，先听基层真实想法
例：例：改用"分组讨论 + 指定反调"的小组，往往能在全员点头前拦下被大集体淹没的关键异见。

看穿盲思的四道裂缝

Key Signs
01

高凝聚 + 强势领导 = 危险组合

大家为了"保持一致"，把争议观点压下去，简单化、模式化思考，再错也听不进。

02

全体一致的共同错觉

谁反对谁就是不团结。当"团结"成了最高政治，真话就成了异端。

03

自我审察

你还没开口，就先把自己否了——"我说了也不会被采纳，算了"。异见死在了喉咙里。

04

成因藏在权力光晕里

领导一发话，下级为面子保留意见，把决策合理化。同质化团队 + 信息封闭，盲思必现。

岛主亲测：小团队最容易出现"老板说完大家沉默"，那沉默不是同意，是埋雷。

识别信号 → 拆掉盲思

Signal to Action
1
识别危险信号全员点头、无人质疑、领导一言堂、会议结束得像走过场——这些都是盲思的前兆。
2
拆开权力让领导最后表态，先听基层。信息从下往上走，异见才不会被上面一句话压死。
3
设一个反调决策前指定一人当"魔鬼代言人"，专门挑漏洞。把反对制度化，而不是靠勇气。
4
分小组讨论先分组讨论再汇总，避免大集体淹没异见，让少数派有说话的房间。
5
可信度加权关键议题用专家意见加权，别让"少数服从多数"把真正懂行的人淹了。

马上能用的事

Put It to Work
✓

决策前指定唱反调者

每次重要讨论，指定一人专门挑漏洞，把"反对"变成岗位职责。

✓

先分组再汇总

大会议前让小组各自讨论，再合并结论，保护少数异见不被淹没。

✓

领导最后发言

开会时让一把手压轴，避免"定调效应"让全场跟着附和。

✓

可信度加权投票

专业议题按懂行程度加权，别让人数压倒真相。

✓

把沉默记下来

散会后问问没说话的人"你真同意吗"，把沉默当信号而非赞成。

什么时候该掏出它

When to Use
团队决策项目评审会创业合伙组织管理重要共识达成前
