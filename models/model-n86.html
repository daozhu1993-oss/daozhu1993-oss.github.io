Overview

写这个系列，我挑的都是能拿来用的框架，不玩虚的。杠杆思维 这篇，先看总览。

一句话总览： 杠杆思维把阿基米德的"支点撬地球"搬进人生：用极小的成本撬动极大的资源，诀窍就是找到推动事情的那个决定性因素——支点。
Origin
岛主解读 / 思维模型合集源自阿基米德杠杆原理的通俗迁移
Field
个人成长 / 战略资源配置、财富与影响力
Core Definition
用可调动的资源作杠杆，找准能重复成功的底层能力作支点，以极小投入撬动极大产出借力 + 硬核支点
Thinking Layer
战略 / 成长从"更努力"到"更聪明"

误用 vs 善用

Bad vs Good
✗ 误用

只有杠杆，没有支点

把"自己"当核心竞争力，人一离开业务就停摆
饭局上认识半个商圈，真办事一个都使不上劲
杠杆越长、方向越错，亏损被同步放大
每天忙到凌晨，收入却纹丝不动
例：例：有人迷信"人脉杠杆"，微信加了几千人，真到借钱、求合作时没人接话——关系没有沉淀成信任。
✓ 善用

支点硬核，杠杆对路

好产品不是支点，做出好产品的机制才是
好员工不是支点，培养好员工的制度才是
杠杆放对了放大收益，放错了放大亏损
老板不可复制，可复制的体系才叫支点
例：例：罗永浩靠"影响力杠杆"直播还了 4 个亿债务；巴菲特靠"时间杠杆"长期持有，让复利把收益滚大。

杠杆与支点的三层拆解

Key Points
01

杠杆本身是你可调用的资源

资源、信息、时间、资本、影响力，都是杠杆。马云 1995 年在西雅图看见互联网，信息就成了他的第一根杠杆。

02

支点是你重复成功的底层能力

好产品不是支点，做出好产品的机制才是。把"自己"当核心竞争力的人，往往一做不大——因为老板不可复制。

03

杠杆不分方向，支点必须硬核

杠杆放对了放大收益，放错了放大亏损。没有硬核支点，杠杆越长死得越惨。

例：那些饭局上认识半个商圈、真办事一个都使不上劲的人，就是杠杆虚胖、支点空心的典型。
04

先找支点，再上杠杆

顺序错了全盘皆输。先打磨那个能反复生效的能力，再用资源去放大它，而不是反过来裸奔上杠杆。

四步找到你的杠杆与支点

Four-Step Model
1
盘点五种杠杆列出你手上的人脉、信息、技能、时间、资金，看清自己到底能借到哪些力。
2
问清你的支点问自己：我的支点到底是什么？它是不是能让我一次次重复成功，而不是只靠我本人顶着？
3
选最小杠杆试水本周就用一个最小杠杆，去撬动一件具体的小事，验证支点是否真的硬核。
4
把支点做成体系把"我擅长"升级为"机制能复制"——好制度、好流程，才是别人抢不走的支点。

马上能用的事

Put It to Work
✓

列出 5 种杠杆

今晚就写：你手上的人脉、信息、技能、时间、资金分别有哪些可调用。

✓

找到你的支点

问自己：哪件事我能反复做成？它依赖我个人，还是依赖一套方法？

✓

本周撬一件小事

选一个最小杠杆（比如一条人脉、一个信息差），去撬动一件具体的正事。

✓

把能力变机制

把你最拿手的事，写成可交给别人的流程，让成功不再绑定在你一人身上。

✓

审视虚胖杠杆

清理那些"看着热闹、使不上劲"的关系与资源，别让它们骗你以为有支点。
