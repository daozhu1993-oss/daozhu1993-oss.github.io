写这个系列，我挑的都是能拿来用的框架，不玩虚的。图尔敏论证模型 这篇，先看总览。

一句话总览： 图尔敏在《论证的运用》里说：三段论太死板。他给了套"实用逻辑"，像法庭辩论一样把道理讲圆——主张、依据、理由、支援、限定、反驳，让你的结论经得起反问。
Origin
图尔敏（英国哲学家）《论证的运用》
Field
逻辑 / 沟通批判性思维 · 说服
Core Definition
用主张+依据+理由+支援+限定+反驳六要素，把结论讲成经得起挑刺的论证把"我觉得对"变成"站得住脚"
Thinking Layer
认知 / 逻辑表达 · 思辨

误用 vs 善用

Bad vs Good
✗ 误用

结论一摆就完，别人一句"凭什么"就卡壳

写方案、汇报只摆结论，被问"凭什么"就懵。
吵架赢在气势，事后说不清凭啥赢。
结论和事实之间根本没桥，含糊带过。
用"你懂的"糊弄，经不起一句反问。
例：例：岛主有回争"该不该加班"，光喊"效率重要"被怼翻——只有主张，没有桥。
✓ 善用

把道理讲圆，经得起挑刺

主张 + 依据先立桩：结论和客观事实都要稳。
正当理由搭桥：说清"为什么依据能推出主张"。
支援 + 限定 + 反驳补漏：法条是支援，"一般情形下"是限定，反例是反驳。
主动列反例，堵住别人的嘴，逻辑闭环才稳。
例：例：岛主用这套争"少加班"——主张"少加班"、依据"出错率升"、理由"疲劳降质"、支援"研究结论"，对方才点头。

关键要点

Key Points
01

主张 + 依据先立桩

主张是你要证明的结论，依据是客观事实。如"哈里是英国人"，依据是"他生在百慕大"——桩不稳，后面全塌。

02

正当理由把桥搭上

为什么依据能推出主张？"百慕大出生即英国人"就是担保。这一步最易被含糊带过，很多人结论和事实之间根本没桥。

03

支援 + 限定 + 反驳补漏洞

法律条文是支援；"一般情形下"是限定；"若他入了别国籍"就是反驳。好论证经得起挑刺，而不是一句"你懂的"糊弄。

04

好论证经得起挑刺

不是堆气势，是主动堵死反驳。逻辑闭环才稳，别人一句反问就垮的不是真说服力。

05

法庭律师就这么干

先抛主张，再堆依据，最后堵死反驳。把生活里的糊涂事，讲成站得住脚的道理。

应用流程

How to Apply
1
写清结论与事实依据先把"你要证明什么"和"客观事实是什么"分开列。桩不稳，后面搭再多桥也白搭。
2
补一句"因为……"把逻辑桥搭出来，别让结论悬空。这一步最能暴露你其实没想清楚的地方。
3
找支援加固用研究、法条、数据给你的理由做担保，让"因为"站得住，而不是空口。
4
主动列反例堵嘴自己先说"除非……"，堵住别人最容易反问的点。逻辑闭环，才算讲圆。

马上能用的事

Put It to Work
✓

重写一条朋友圈观点

用"主张 + 依据 + 理由"三句话重讲你昨天的某个看法，看还站不站得住。

✓

给方案加一座桥

明天汇报时，每个结论后补一句"因为……"，别让结论悬空。

✓

预演反驳

重要沟通前，先写下别人会怎么怼你，准备好回应，别临场卡壳。

✓

读一份论证文

找一篇带"依据—理由—限定"的文章拆解结构，照着学怎么讲圆。

✓

戒"你懂的"

本周说话凡结论，都要给得出桥。含糊带过的地方，就是逻辑漏点。
