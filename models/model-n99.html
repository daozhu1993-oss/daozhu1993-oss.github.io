先一句话总览

Overview
N
n

写这个系列，我挑的都是能拿来用的框架，不玩虚的。控制论 这篇，先看总览。

一句话总览： 控制论研究动物和机器如何靠"反馈"自动奔向目标——先看清可能性空间，再靠负反馈一次次缩小差距，把目的和因果统一起来。
Origin
维纳《控制论》（1948）神童数学家维纳创立，研究反馈与自组织
Field
系统科学 / 管理 / 自动化反馈是核心机制
Core Definition
通过反馈闭环，让系统自动缩小与目标的差距目的与因果被统一起来
Thinking Layer
系统 / 决策看"如何自动达标"的视角

误用 vs 善用

Bad vs Good
✗ 误用

只下命令，不接反馈

以为管团队就是下命令、盯进度
设了目标却没可测量的"差距指标"
一次指令定终身，错了也不纠偏
把正反馈当动力（越骂越不爱学，恶性循环）
例：例：岛主起初天天盯人，大家缩手缩脚；或越骂越厌学，雪球越滚越大。
✓ 善用

建负反馈闭环

给目标设一个可测量的差距指标
定期看"还差多少"，自动纠偏（如周报差距反馈）
不靠一次指令，靠一次次小修正积累
区分负反馈（纠偏）与正反馈（放大），别用错
例：例：体温靠出汗、发抖永远回 37 度；老鹰抓兔靠眼睛不断报告差距。

关键要点

Key Takeaways
01

先看可能性空间

事物发展有无数可能，控制就是缩小它、奔向你要的状态。治病目标是"好转"，手段是隔离吃药；人生每个选择也锁定一条路径。

02

负反馈是定海神针

鹰抓兔：眼睛不断报告"还差多远"，翅膀一次次缩小差距。体温热了出汗、冷了发抖，永远往 37 度回。

03

当心正反馈

正反馈相反，越骂越不爱学，恶性循环，像雪球越滚越大。它不是纠偏，是放大偏差，用错了很危险。

04

黑箱法：看输入—输出

看不透内部，就观察"输入—输出"猜结构。不用懂脑，也能"听其言观其行"知其心。

05

功能模拟：模仿机制

导弹模仿鹰抓兔，是功能模拟而非结构模仿。抓到本质机制，就能跨领域复用。

三步用上控制论

How to Apply
1
定义目标写出可测量的差距指标，让"还差多少"看得见。
2
建反馈通道定期采集"实际 vs 目标"，别让信息断流。
3
自动纠偏差距一出现就小修正，像体温回 37 度一样自然。
4
多次累积靠一次次小修正靠近目标，别指望一次到位。
5
别贪大一次纠偏不算数，次次纠偏才抵达终点。

马上能用的事

Put It to Work
✓

✓

别把恶性循环当激励，该纠偏时纠偏。
