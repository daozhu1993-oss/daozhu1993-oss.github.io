先一句话总览

Overview
SCAMPER
scamper

写这个系列，我挑的都是能拿来用的框架，不玩虚的。SCAMPER 这篇，先看总览。

一句话总览： 困住时，用这 7 把钥匙撬开脑子。SCAMPER 像一份七个问题的检查单，逼你从七个角度重新审视手头的东西，总能撬出点新意思。创新常常不是凭空造新世界，是把旧东西换个角度拧一下。
Origin
罗伯特·艾伯尔Robert Abell，美国心理学家，创作了这份七问创新检查单。
Field
创新思维 / 产品改进头脑风暴、老功能救活、流程优化都好使。
Core Definition
七问检查单替代 / 合并 / 修改 / 转用 / 调适 / 消除 / 反转重组。
Thinking Layer
发散创新层 / 创意生成在"想清楚"之前，先帮你把灵感逼出来。

七把钥匙拆解

The Seven Keys
01

替代 Substitute

能不能换个零件、换个人、换个材料？像把猪油换成橄榄油，味道全变，成本也可能跟着降——换的不一定是物料，也可以是人力。

02

合并 Combine

拼一起？两功能合并成一个按钮，省掉一步。把零散的东西拢成一团，常能省下不必要的环节。

03

调适 / 修改 Adapt · Modify

借鉴谁？放大？手机摄像头转去扫描文档就是转用，把功能挪到别处用，往往比重新造更省力。

04

转用 Put to other uses

挪到别处用？一个设计换个场景就成新东西。旧功能的新用法，常常是创新的藏身处。

05

消除 Eliminate

砍掉什么？很多创新是"删掉一步"——自助收银就是删掉了收银员。少即是多，删比加更值钱。

例：岛主删掉最劝退的作业，完课率反而涨了 18%。
06

反转 / 重组 Reverse

倒过来会怎样？把流程倒过来排，常能省掉冗余环节。把"用户找功能"改成"功能找用户"，留存直接起飞。

三步用起来

Put SCAMPER to Work
1
铺七格表拿一张 SCAMPER 七格表，把你的产品 / 方案放中间，让它看着你。
2
每格逼问每格逼自己写至少 1 个改动点，不准空——空着就说明你还没真想。
3
挑两个就试挑可行性最高的 2 个，这周就试，别只停留在纸上，灵感要落地才算数。
