写这个系列，我挑的都是能拿来用的框架，不玩虚的。SCQA 排在第 6，是因为我见过太多人——材料准备得满满当当，十分钟汇报讲完，领导只回一句「所以你的结论是什么」。内容不差，差的是「怎么讲进去」。

一句话总览： SCQA 是一条最符合大脑思考习惯的表达故事线——先铺情境建立共识，再抛冲突打破平静，自然引出问题，最后给出答案。它不是内容的替身，而是让好内容「听得进去」的骨架。
Origin
麦肯锡方法论源自《金字塔原理》的结构化表达框架（Situation-Complication-Question-Answer）。
Field
沟通表达 / 工作汇报 / 文案写作演讲、同步信息、争取资源都用得上。
Core Definition
四段故事线 S·C·Q·A情境 → 冲突 → 问题 → 答案。
Thinking Layer
框架型 / 叙事结构在「想清楚」之后，解决「怎么讲清楚」。

SCQA 结构表达

Situation · Complication · Question · Answer
S 先建共识：一个双方都认同的背景
C 再打破平静：点出现实与理想的落差
Q 自然引出：此刻大家心里的核心问题
A 顺理成章：有铺垫，答案备受期待
例：灰指甲广告——你有灰指甲(S) → 一个传染俩(C) → 问我怎么办(Q) → 用亮甲(A)。

SCQA 四段拆解

The Four Moves
S

情境 Situation

建立共识。描述你与听众都认同的背景，简洁、客观、无争议——这是后面向前推进的共同出发点。

例：本季核心目标：用户活跃度 +20%。
C

冲突 Complication

打破平静。点出现实与理想的落差、变化或挑战，制造张力，回答「为什么现在要谈」。

例：新用户次日留存 −15%。
Q

问题 Question

引出焦点。基于冲突，提出大家此刻都会产生的核心问题，精准指向你要给的答案。

例：怎么把人留下来？
A

答案 Answer

给方案。你整个表达的核心观点，因为前面铺垫，此刻显得顺理成章、备受期待。

例：启动新用户护航计划，从三方面着手……

应用流程

Build Your SCQA
1
定 S 情境：找一个双方都认同、无争议的事实背景，越简洁越好，这是共同出发点。
2
造 C 冲突：点出与 S 的落差或变化，制造「为什么现在要谈」的张力。
3
抛 Q 问题：顺着冲突，抛出一个听众心里自然冒出的核心问题。
4
给 A 答案：用最强结论回应 Q，此时答案已被期待、顺理成章。
ASC 开门见山式：答案 → 情境 → 冲突（适合领导已知背景、时间紧）
CSA 突出忧虑式：冲突 → 情境 → 答案（适合争取资源、强调危机感）
QSCA 突出信心式：问题 → 情境 → 冲突 → 答案（适合演讲、文案开头引好奇）

Put It to Work
✓

开口前先写 S-C-Q-A

✓

S 要双方都认

情境别夹带争议，否则共识没建起，后面全塌。

✓

C 必须戳痛点

没有冲突就没有张力，听众不会关心你的答案。

✓

Q 要对准 A

你抛的问题，必须被后面答案精准接住。

✓

赶时间用 ASC

领导已知背景，直接给答案再补情境冲突，省时。

✓

文案开头试 QSCA

想抓人，先抛「如何用一年改变自己？」再展开。
