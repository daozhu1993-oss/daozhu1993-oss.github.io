先一句话总览

Overview
STRATEGYC
strategyc

写这个系列，我挑的都是能拿来用的框架，不玩虚的。思考战略罗盘 这篇，先看总览。

一句话总览： 真正的战略不是一句口号，而是四个维度同时回答一个问题——凭什么赢、去哪怎么去、变了怎么办、能不能做到。大多数公司的战略只做了四分之一，所以永远停在 PPT 上。

好战略与有战略在上方（定方向），实战略与快战略在下方（稳落地、能应变）。四象限缺任何一个，战略都是残废。

Origin
岛主解读 · 战略落地框架素材未明示单一提出者，按「岛主解读」框架整理，不杜撰权威出处。
Field

误用对比

Bad vs Good
✗ 误用

残缺战略（只做四分之一）

年度战略会只在画「有战略」那一格——定目标、排计划、分任务
从没认真想「凭什么赢」，竞争优势是空的
没建应变机制，竞品一动就慌，不知该坚持还是掉头
没盘点组织能力，目标再宏大也是空谈
例：结果：年底一看，年初定的「战略目标」一个都没落地——因为另外三个象限根本没写。
✓ 善用

完整罗盘战略（四个锚点同时撑住）

好战略：想清凭什么赢（定位 → 竞争优势 → 产业生态）
有战略：画清去哪、怎么去（战略地图 + 战略意图）
快战略：建应变机制（敏捷迭代 + 认知升级）
实战略：盘清组织能力（资源杠杆 + 跨越鸿沟）
例：战略是一张需要四个锚点同时撑住的网。少一个锚点，整张网就兜不住任何东西。

关键要点拆解

Key Points
01

好战略 · Good Strategy · Why We Win

我们凭什么赢？；定位视角：选对战场，不在红海里硬拼；竞争优势：找到别人抄不走的差异化；产业生态：让生态伙伴跟着你一起强；核心句：与众不同，由外及内

02

有战略 · Have Strategy · Where & How

我们要去哪、怎么去？；规划视角：把方向变成可讲的蓝图；战略地图：把目标拆成可执行路线图；战略意图：明确「不做」什么和「做」一样重要；提醒：光有这块，只是战略的一半

03

实战略 · Solid Strategy · Can We Do It

我们有本事做到吗？；内部稳定性：组织稳不稳；资源杠杆：手里的牌够不够；组织能力：团队能不能扛；跨越鸿沟：从「现在的能力」到「战略需要的能力」

04

快战略 · Fast Strategy · If It Changes

环境变了怎么办？；外部适应性：市场变了接不接得住；敏捷迭代：小步快跑，不一次定终身；认知升级：老板的认知天花板 = 战略天花板；核心句：不能进化的战略，就是一张废纸

应用流程

How to Use
1
填满四象限拿出你最新的战略 PPT，对着四个区域逐个检查：好战略？有战略？快战略？实战略？哪个区域是空的？哪个只有一句空话？
2
找缺口大多数公司缺的是「实战略」——认真算清要做到这件事，团队需要什么能力、现在差多少、怎么补。这是最扎心也最该补的一块。
3
定期转一圈战略不是年初定完就锁进抽屉。每个季度拿这张罗盘重新审视一遍：外部环境变了没？我们的优势还在吗？组织能力跟上目标了吗？

马上能用的事

Put It to Work
✓

战略会前先自问四问

凭什么赢？去哪怎么去？变了怎么办？能做到吗？先把这四问写在会议邀请里。

✓

补上「实战略」

列出目标与现有组织能力的鸿沟，排出补能力的计划——这是多数公司唯一的缺口。

✓

战略 PPT 加一页罗盘

四个区都填满、不许留白，再拿去上会。空着一格的，当场打回补。

✓

每季度转一圈

固定节奏拿罗盘更新三问：外部变没变？优势还在？能力跟上目标？

✓

把「不做什么」写进战略意图

明确放弃什么，和明确做什么同样重要——战略是取舍，不是清单。

✓

建「快战略」应变机制

竞品一动就慌？提前设好敏捷迭代 + 认知升级的触发条件，别等乱了再想。
