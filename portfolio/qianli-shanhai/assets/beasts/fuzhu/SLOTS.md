# 夫诸 · 画师图层槽

M1 用的是程序线稿（`fuzhu.svg`）和运行时画的岩面、瀑布。把 PNG 放进本目录后，在 `slots.json` 里把对应项写成文件名（例如 `"resident": "fuzhu-resident.png"`），刷新就会盖过占位。背景全部透明。颜色限制在真迹矿物色：石青 `#2E6184` / `#5B8DB0`，石绿 `#3D7A63` / `#9CC0A0`，赭石 `#8D6F37`，蛤粉 `#F1EADB`，松烟 `#272315`。不要霓虹，不要投影。

| 文件 | 尺寸 | 状态 | 画面 |
| --- | --- | --- | --- |
| `fuzhu-fenben.png` | 768×1024 | 入景线索 | 粉本线稿，游戏会把它压到约 25% 不透明 |
| `fuzhu-mist.png` | 1024×1280 | 引泉成功，雾中现身 | 四角白鹿，角上挂水珠，四周留白给雾 |
| `fuzhu-resident.png` | 768×1024 | 潭边常驻 | 侧身站立，脚下留一点地面 |
| `fuzhu-resident-2.png` | 768×1024 | 常驻第二帧 | 同一站姿，头或前蹄微动，和上一张交替 |
| `fuzhu-album.png` | 1200×1600 | 画札左页 | 工笔整页，底子可以空，游戏会垫那段真迹 |
| `rock-dry.png` | 768×1280 | 干瀑修补岩面 | 竖向岩缝，没有水。盖住真迹瀑布的那一块 |
| `waterfall.png` | 768×1280 | 复流之后 | 同一轮廓的水帘，透明底，游戏叠在岩面之上 |

坐标：夫诸在全卷归一化位置 x = 0.679（卷首在右，x = 1），区段 0.663–0.695。岩面和水帘对应该区段的悬崖，不是整卷。

当前占位：

- `fuzhu.svg`：四面角的白鹿铁线，成功、常驻、粉本都用它，靠透明度和位置区分状态。
- 岩面、瀑布、潭边雾：`src/fx/Overlay.js` 里用画布笔画，色从真迹石青石绿取。
