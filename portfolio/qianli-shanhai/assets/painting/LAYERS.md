# 画卷分层与瓦片

真迹来源是仓里已有的六段故宫数字本 `section_0.jpg`–`section_5.jpg`（左到右拼成 22486×900），与设计稿引用的维基共享资源公有领域全卷是同一件画，只是这一版的高度是 900 而不是 1600。概览用现成的 `qianli_panorama_hi.jpg`（8000×320）。

## 怎么切的

没有做语义抠图。远、中、近是三条水平带，在着色器里按纹理 v 交叉淡化：

- 远：画面上方约 45%，视差系数 −0.08（山走得慢）
- 中：整幅，系数 0，静止时画面就是这一层，和真迹对齐
- 近：画面下方约 40%，视差系数 +0.07（水岸走得快）

系数相对镜头中心缩放，屏幕边缘的错动不超过视宽的 6%。全卷层（概览）系数为 0，三层叠成一张平的。带与带之间有一段羽化，避免硬切。

重跑切图：`python3 scripts/build-tiles.py`（需要 Pillow）。脚本把六段拼回去，再按 1024×900 切成 `assets/tiles/lod1/000.jpg` 起的 22 张，并写 `assets/tiles/manifest.json`。

## 运行时怎么加载

- 概览只上传那一张 8000×320。
- 游观和入景只上传视口左右各一块的 lod1，最多留 8 张，其余释放。
- 远中近三层共用同一张 GPU 纹理，只是几何体和透明带不同。
- 入景 2.4× 会把 900px 的源图放大，边缘偏软。画师或以后换上维基 1600px / 6110px 源时，按同样的 manifest 字段（`x`、`w`、`h`、`file`）替换 lod1 即可。

褪色和色归不另做贴图。一条 2048 格的一维复原度纹理沿卷面 x 喂给着色器：未复原饱和度 0.40，再混一层熟绢 `#E9DFC8`。
