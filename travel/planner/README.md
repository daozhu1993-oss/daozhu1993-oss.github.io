## 当前产品

网页是静态旅行规划工具。访客填写自己的 **API 地址、模型名、Key**，验证后整理需求、生成国内2—30天往返旅行草案（全程自驾，或飞机往返＋当地租车），再用自然语言修改。没有固定供应商、公共模型额度或后台代付；不再要求访客填写站点访问码，也不会调用旧 `/api/plan`、`/api/brief` 或 `/api/health`。

浏览器直接向访客指定的服务商请求。现有 GitHub Pages 可以托管这套代码，不需要额外部署模型代理。API 调用计入访客账户；本站没有新增服务订购或付费调用。网站托管条件及用户的模型定价由相应平台决定，不承诺所有服务永远免费。

## 使用方法与接口范围

1. 在服务商控制台取得 Key、OpenAI 兼容 Base URL、模型名。
2. 在网页输入三项，点击“验证连接”。允许填写 Base URL（例如 `https://provider.example/v1`）或完整 `/chat/completions` 地址；示例域名不是可用服务。
3. 验证成功后，可以“整理我的想法”，核对并采用条件，或直接填写表单。
4. 生成后按天查看。调整先产生预览，“采用这份方案”才替换当前行程；冲突不能采用。
5. 可以保存完整 HTML。刷新、清除或离开页面后 Key 消失；行程也不自动持久化，请先导出。

兼容条件：HTTPS、Bearer Key、`POST /chat/completions`、`response_format: {type: 'json_object'}`、`max_tokens`、非流式 `choices[0].message.content` JSON 字符串和 `finish_reason: stop`。服务商必须允许浏览器跨域访问。原生 Claude/Gemini 等非此格式的接口不能仅凭 Key 通用；可使用其服务商提供的兼容入口。不能填写聊天网页或会员账号信息。

连接验证是真正的一次小模型请求（输出上限512 token），不是只看 Key 长相；不会查询余额或读取用户其他资源。需求整理上限4096输出token；规划/修订按总天数分配输出上限：2—4天8192、5—8天16384、9—14天32768、15—30天65536。长行程会增加等待时间和用户API用量。DeepSeek官方域名在验证连接与需求整理时关闭思考；生成、修改及一次修正时启用 `thinking: {type: enabled}` 和 `reasoning_effort: low`，为时间约束推算保留推理能力，同时维持已有输出上限。其他服务商不发送这些专用参数。每次规划最多两次调用（初稿+一次冲突修正），其余失败不自动重试。验证/整理/生成/调整会产生用户自己的API用量；取消只能停止网页等待，不能保证服务商不再处理或不计费。

## 真实性边界

通用模型接口**没有接入地图、联网搜索、天气、票务与房态**。景点是模型建议，里程、驾驶时长、费用是估算；不生成伪造来源或坐标，也不把直线距离转换成“实测”路程。页面与导出均标明道路未核验。地图按钮只是带地点名称打开外部地图，由用户确认位置与路线，不代表网站查询过道路。

沿用原有日期连续性、总天数、末日返程、返程截止、每日驾驶小时与可选公里数上限、停车缓冲、餐饮与儿童午休、必去/避开和全团预算校验。检查基于模型估算，只能证明草案内部满足这些条件，不能证明现实可行。“全程避开高原”仍因未查途经道路海拔而阻止采用。未知或缺失车程不会填0补齐。明显有冲突的方案显示问题，最多让模型修正一次。

对站内已知且准确匹配的出发/目的城市，若填写了每日公里上限，会先用城市位置的保守直线往返下限筛查明显不可能的总里程预算。这个筛查只用于否决，绝不把直线距离填成道路里程；未命中城市或通过粗筛不代表路线可行。模型也可返回 `needs_input` 说明约束冲突，不必硬编完整行程。

本轮用户确认的目标是自带API的框架。获得可信实时攻略仍需未来单独选择数据能力；不能把现有框架描述为已完成真实道路/实时资料联调。

## 凭据与隐私

- Key 只在当前页面闭包中临时保存，验证成功后清空输入框；不写 localStorage、sessionStorage、Cookie、URL、日志或导出。
- API 地址变化会清除 Key，模型或 Key 变化会取消连接就绪状态。
- 仅接受 HTTPS，拒绝 URL 内嵌密码、查询参数和片段；禁止自动跟随重定向，不携带浏览器Cookie、不发送referrer。
- Key 只进入该地址的 Authorization 请求头，不写入模型提示词；不展示服务商原始错误（避免某些网关回显密钥）。
- 所有模型文本按普通文字转义；不执行生成的 HTML。模型提供的来源链接或坐标不采纳。
- 前端内存并非绝对保密，用户须信任网页代码、浏览器环境和所填API服务商。本站没有后台代理，不存在“自动换免费服务”的回退路径。
